# Content Engine (Script Studio)

## Overview
The **Content Engine** powers the Script Studio in Phase 12. It transforms child content item specifications, parent evidence claims, originality plans, and brand rules into structured, format-tailored video scripts and companion copy.

## Core Capabilities
1. **7-Section Evidence-Grounded Architecture:**
   - `hook`: High-impact opening anchored in empirical findings.
   - `problem_context`: Real-world pain point or baseline status quo.
   - `method_test`: Reproducible testing setup, harness, or benchmark conditions.
   - `evidence`: Quantitative measurements, citation nodes, and verified claims.
   - `result`: Outcome, winner, or failure analysis.
   - `interpretation`: Practical implications, hardware takeaways, and cost trade-offs.
   - `cta`: Brand-consistent closing call to action.

2. **Section-Level Refinement Tools:**
   - `regenerate`: Fresh take with preserved claim references.
   - `shorten`: Tightens pacing for rapid cadence (e.g. 50-60s Shorts).
   - `expand`: Adds technical depth and operational nuances.
   - `make_clearer`: Removes jargon and enhances conversational flow.
   - `more_evidence`: Injects verified claims and quantitative data.

3. **6-Dimension Quality Gates:**
   - Evaluates: **Evidence**, **Brand**, **Originality**, **Viewer Value**, **Niche Fit**, and **Repetition**.
   - No single opaque score.
   - Hard blocks on:
     - `off_niche`
     - `critical_brand_failure` (e.g., banned clichés)
     - `unsupported_claim`
     - `missing_original_value`
   - Explicit human override capability recorded for auditability.
